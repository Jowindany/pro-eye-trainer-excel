Privacy & help

Pro Eye Trainer is a break timer with optional ball-following exercises. It runs in an Excel task pane.

Your data

The add-in code does not read or change your workbook, send worksheet data, use analytics, or require a login. Preferences are saved in browser local storage. Delete site data to clear them. The hosting provider may keep standard request logs. Microsoft hosts the Office JavaScript runtime.

Using the timer

With the v1.3 shared-runtime manifest, the timer continues when the panel is hidden while the workbook stays open. Select a break interval and press Start timer. At break time, look away from the screen. Each break lasts 20 seconds, then a new work interval starts automatically. Exercises are optional and can be started manually. Pause and Stop are always available during a running session. Settings take effect on a new session.

Closing the panel leaves the work/break timer running on supported Excel clients. An Office dialog opens at break time for 20 seconds, closes automatically, and includes a visible alert and a three-note chime (enabled by default). Browser audio restrictions or muted speakers may prevent sound. Use Test sound first. Closing the workbook stops the runtime. Opening the workbook again requires starting a new timer. Browser/device suspension can delay reminders; no system notification or background alarm is promised. Exercise movement pauses when the page reports itself hidden.

The add-in uses SharedRuntime 1.1 and requests only Restricted Office permissions and does not call workbook APIs. This is a comfort routine, not treatment or a promise of improved vision. Stop an exercise if uncomfortable.
