Install in Excel

First host the files in this web folder on an HTTPS static website. This page generates the Excel installation file for your website.

  1. Check that taskpane.html opens from your HTTPS website.
  2. Generate and download the manifest above.
  3. In Excel Online, go to Home → Add-ins → More Settings → Upload My Add-in, then select the XML file. Menu labels can vary; see the included README for Microsoft’s account-specific instructions.
  4. Open Pro Eye Trainer and press Start timer.

If custom add-ins are disabled at work, ask your Microsoft 365 administrator to deploy it. No Script Lab is required.
